# WikiChaudron (app installable)

Compagnon du chaudron d'**Alchemy Factory 1.0** : recettes du chaudron, machines, coûts, planification et atelier d'usine.

**Ouvrir ou installer** : https://zartuf27.github.io/wikichaudron-app/

- Ordinateur (Edge, Chrome) et Android : bouton « 📲 Installer » ou icône d'installation dans la barre d'adresse.
- iPhone, iPad : Safari → Partager → « Sur l'écran d'accueil ».
- Hors ligne : `WikiChaudron.html` est l'app complète en un seul fichier.

Projet de fan, non affilié à l'éditeur du jeu. Les données et icônes du jeu appartiennent à leurs auteurs.
